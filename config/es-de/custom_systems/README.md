# Custom systems

The included `es_find_rules.xml` teaches ES-DE 3.4.1 about the package name
used by current ARMSX2 releases while retaining compatibility with older
ARMSX2 package names.

Add reviewed ES-DE `es_systems.xml` fragments here when needed. Keep paths
portable and never commit ROMs, BIOS files, console keys, credentials, or paid
application packages.
