# Custom systems

The included `es_find_rules.xml` teaches ES-DE 3.4.1 about the package names
used by current ARMSX2, Eden, X1 BOX and XenDroid releases while retaining
compatibility with older ARMSX2 package names. `es_systems.xml` defines the
Switch, Xbox and Xbox 360 directories and their direct-launch commands.

Keep paths portable and never commit ROMs, BIOS files, console keys,
credentials, or paid application packages.
