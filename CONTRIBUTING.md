# Contributing

Small, reviewable improvements are welcome. Keep scripts idempotent, preserve
the RP6 identity gate, and prefer official project pages or upstream release
repositories. Never commit APKs, ROMs, BIOS/firmware, console keys, credentials,
tokens, device serials or proprietary game data.

Before opening a pull request, run `make validate`. Explain any command that
changes Android settings or permissions and provide a safe rollback.
